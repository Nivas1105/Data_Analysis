# Data Analysis Projects in Python

This repository contains a collection of data analysis projects completed using Python and its powerful data science ecosystem. The focus is on demonstrating practical skills in data cleaning, exploratory analysis, visualization, and insight generation.

---

### Core Competencies Demonstrated
-   **Data Wrangling & EDA:** Proficient in using **Pandas** and **NumPy** to clean, transform, and explore complex datasets.
-   **Data Visualization:** Skilled in creating insightful and publication-quality charts using **Matplotlib**, **Seaborn**, and **Plotly**.
-   **Statistical Analysis:** Applying statistical methods to identify trends, correlations, and significant patterns in data.
-   **Predictive Modeling:** Experience with **Scikit-learn** for building fundamental machine learning models like regression and classification.
-   **Problem Solving:** Translating business questions into data-driven hypotheses and delivering clear, actionable answers.
